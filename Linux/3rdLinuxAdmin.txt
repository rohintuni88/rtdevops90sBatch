How to provide Sudo access to Ramesh user: -
  wheel --> It is the group in linux for give the superuser access or sudo access.
  usermod -aG wheel ramesh    --> Now ramesh is Sudo access
  sudoers files ---> /etc/sudoers
  
  Now We dont give all Admin /Fullaccess to Ramesh, We want gove only few Admin access.

  1st --> Remove ramesh from wheel group
         gpasswd -d wheel ramesh
  2nd  --> ramesh is one can do useradd, usermod (to add in to groups)  only, Others operations cant do.

       We have a /etc/sudoer.d   --> sudoer.d is dir in /etc folder.
       Open the /etc/sudoers file, Copy the -->root    ALL=(ALL)       ALL
       go to /etc/sudoer.d  --> cd /etc/sudoer.d
       create vi ramesh file
       Add root    ALL=(ALL)       ALL   and change it to --> ramesh    ALL=(ALL)       ALL
       use command --> which useradd it shows --> /usr/sbin/useradd
       update it to --> ramesh    ALL=(ALL)    /usr/sbin/useradd,  /usr/sbin/usermod
       :wq! to save the file.
       To verify vi editor syntax --> visudo -c 

  Now, we need to give admin permissions to the group, who joined in this group, they are admins.
     groupadd devops-user-manager  --> Goups created
     now, /etc/sudoer.d  --> cd /etc/sudoer.d --> create vi devops-user-manager  --> %devops-user-manager   ALL=(ALL)    /usr/sbin/useradd,  /usr/sbin/usermod  --> % is for Group.
     usermod -g devops-user-manager ramesh 
     then ramesh have  /usr/sbin/useradd,  /usr/sbin/usermod this permissions.
