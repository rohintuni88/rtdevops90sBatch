If you want the perminent changes in a file
  sed -i '1a\hello' users   --> a - after the line
  sed -i '1i\hello' users   --> i - befor the line
  sed -i 's/systemd/SYSTEMD/g --> change small letter systemd to SYSTEMD, s means substitution, g means global
  sed '1d' users --> to delete the 1st line
  sed '/shutdown/d' users --> to delete all shutdown word in the file.
  sed '2c\Hi' users --> change/replace the line num2 text / context to Hi.
  sed '/shutdown/d' users  --> delete the word shutdown
  cat users
